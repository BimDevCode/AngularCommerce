## Online shop on **Angular** for testing library integrations and how they work

This is the frontend repository for an **Online Shop Application**, built using **Angular** and **Angular Material Design**. The application provides a responsive and user-friendly shopping experience, leveraging modern web development practices.

---

## **Features**
- User authentication and authorization (login, signup).
- Browse and search for products.
- Add to cart, view cart, and proceed to checkout.
- Responsive design using **Angular Material Design**.
- Product filtering and sorting by categories and price.
- Integrated with a backend REST API for product and order management.

---

## **Technologies Used**
- **Angular** (v16+): Framework for building the frontend.
- **Angular Material**: Provides a modern, responsive UI.
- **RxJS**: Reactive programming for asynchronous data streams.
- **SCSS**: Styling for a clean and maintainable design.
- **TypeScript**: Strongly typed JavaScript for robust code.
